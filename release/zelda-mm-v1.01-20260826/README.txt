젤다의 전설: 무쥬라의 가면 한국어 패치 v1.01
Release 2026-08-26

[상태]
정식 공개판 v1.01입니다.

[로고 선택]
1. Nintendo 64: apply_nintendo64.bat
2. 현대 컴보이 64: apply_hyundai_comboy64.bat

두 버전의 게임 내용은 동일하며 시작 시 표시되는 Nintendo 로고만 다릅니다.
패치 파일: mm_ko_v1.01_nintendo64.xdelta / mm_ko_v1.01_hyundai_comboy64.xdelta

[v1.01 주요 수정]
- 푸른물약 -> 파란 물약 통일 및 아이템 이름 그래픽 갱신
- 마니야 / 전당포 -> 장물점 통일
- 데크 공주, 우유, 페더 소드, 진실의 가면, 가로 가면 설명 수정
- 진실의 가면 설명을 `[C]로 쓰면 가십 스톤과 동물의 / 마음을 읽을 수 있다`로 정정
- 봄버즈 수첩 번호 표기를 1. / 2. / 3. / 4. 형식으로 수정
- 키튼 퀴즈의 팅글 주문 선택지 수정
- 기~나긴 회의를 끝내 준 답례 문구 수정
- 데크 공주 대사의 과도한 유아체를 정리
- 폭발 가면 용어 통일 상태 재검증
- 기존 황금 스탈튤라 카운터, 활공의 노래 목적지, 이름 입력 관련 런타임 패치 보존 확인
- v1.01 재빌드 과정의 한글 폰트/charmap 불일치 문제 수정 및 재발 방지 검증 추가

[사용 방법]
1. ZIP의 모든 파일을 한 폴더에 압축 해제합니다.
2. 원하는 로고의 BAT를 실행합니다. 원본 ROM을 BAT 위로 드래그 앤 드롭해도 됩니다.
3. 패처는 원본 MD5/SHA-256을 확인한 뒤 Xdelta를 적용합니다.
4. 결과 ROM의 MD5/SHA-256까지 일치해야 최종 파일로 확정됩니다.
