드라큘라 성을 자유롭게 탐색하는 액션 RPG

알루카드가 되어 드라큘라 성 내부를 탐험하는 작품입니다. 새로운 장비와 이동 능력을 얻으면서 막혀 있던 길을 다시 찾아가고, 숨겨진 방과 새로운 통로를 발견하게 됩니다.

확장되는 탐험성의 각 구역이 서로 이어져 있어 이전에 방문한 장소로 되돌아가는 과정도 중요합니다.

무기·마법·변신다양한 장비와 특수 능력의 조합에 따라 전투와 탐색 방식이 달라집니다.

통합 패처 · 다운로드 안내

일반판 v0.9b / S판 · 통합 패처 준비 중

월하의 야상곡 · 일반판 / S판 선택형 패처

하나의 패처에서 ① 일반 PlayStation판 또는 ② 새턴 콘텐츠 이식판 S를 선택하는 방식으로 준비 중입니다. 배포 파일은 티스토리의 단일 게시물에서 제공할 예정입니다.

현재 다운로드 링크는 등록되지 않았습니다. 실제 배포 패키지가 완성되면 링크·ZIP 해시·선택 버전별 MD5를 확인해 이곳에 안내합니다. 게임 원본 파일은 제공하지 않습니다.

패치 적용 방법

  1. 통합 패처가 지원하는 일본어판 원본 디스크 이미지와 세이브 파일을 백업합니다.
  2. 티스토리에서 패처 파일을 받은 뒤 압축을 해제하고 실행합니다.
  3. 버전 선택 화면에서 ① 일반판 또는 ② 월하의 야상곡 S를 선택합니다.
  4. 패처의 안내에 따라 원본 이미지를 지정하고 패치를 적용한 뒤, 생성된 해당 버전의 게임 이미지로 실행합니다.

위 방법은 계획 중인 패처의 사용 흐름입니다. 실행 파일 이름과 실제 지원 리비전은 패처 완성 시 확정합니다. 일반판과 S판의 세이브 파일은 서로 호환되지 않습니다.

파일 이용에 관한 권리 및 책임 고지

파일 다운로드 전에 아래 사항을 반드시 확인 바랍니다.

  1. 원칙적으로, 해당 기종의 원본 디스크 또는 카트리지를 보유한 분이 개인적으로만 이용한다는 전제 하에 본 한글패치 파일을 다운로드할 수 있습니다.
  2. 상기 A항 조건에 해당하지 않는 분이 본 한글패치 파일을 다운로드하여 이용할 경우에 발생하는 모든 책임은 이용 당사자에게 있으며, 패치 제작자는 어떠한 책임도 지지 않습니다.
  3. 본 한글패치 파일 자체를 제작자의 허가 없이 타 사이트에 재배포하지 말아 주시고, 재배포를 원하실 경우 패치원본 게시물의 링크를 공유해 주시기 바랍니다.(아카이빙 포함)
  4. 본 게시물의 본문 글 일부 또는 전체를 무단으로 옮겨 작성하지 말아 주시기 바랍니다. 단, 타 사이트에서 발췌하거나 인용한 문구에 대해서는 예외로 합니다.
  5. 본 한글패치 파일을 이용하여 금전적 이득을 취하는 모든 행위를 일절 금합니다. 해당 행위로 발생하는 모든 책임은 이용 당사자에게 있으며, 패치 제작자는 어떠한 책임도 지지 않습니다.(패치 파일 자체 및 패치 롬 파일 판매, 패치 롬 카트리지 제작 및 판매, 웹하드 등 상업적 사이트 업로드, 토렌트 사이트 공유 등)
  6. 상기 C·D·E항의 금지 행위가 적발된 경우, 또는 본 한글패치 파일 공유로 인해 원저작자 및 유통사, 기관의 요청이 있을 경우 예고 없이 게시물이 비공개 처리될 수 있으며, 향후 작업 예정인 작품의 한글패치 파일도 공유하지 않을 수 있습니다.
