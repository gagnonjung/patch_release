INTRODUCTION

여러 세대의 겟타가 한자리에 모이는 대결전

1999년 PlayStation으로 발매된 《겟타로보 대결전!》은 여러 세대의 겟타로보와 파일럿이 한 작품에 등장하고, 전투와 합체·변형, 에피소드 연출을 함께 즐길 수 있는 작품입니다.

TV 애니메이션과 코믹스, 진 겟타 계열의 설정이 한 게임 안에서 교차하기 때문에 기체와 기술, 인물의 차이를 찾아보는 재미도 큽니다. 이번 한국어 패치는 그 분위기를 해치지 않으면서 게임 본편부터 영상 연출까지 최대한 자연스럽게 이어지도록 작업했습니다.

02 / OVERVIEW

개요

처음에는 대사와 메뉴, 몇몇 그래픽만 손보면 될 줄 알았습니다. 그런데 플레이할수록 ‘여기도 고치고 싶다’는 곳이 계속 보여, 결국 게임 전체를 다시 훑어보게 됐습니다.

스토리와 전투 대사, 메뉴와 이름·기술명은 물론 에피소드 제목과 각종 화면도 하나씩 다듬었습니다. 한 군데를 고치면 다른 곳이 눈에 들어오는 식이라, 마지막까지 에뮬레이터 플레이 화면을 보면서 계속 손봤습니다.

특히 에피소드 제목과 다음 화 예고, 영상 자막은 단순히 한국어를 넣는 것보다 원래 작품의 분위기를 얼마나 자연스럽게 살릴 수 있느냐를 더 중요하게 생각했습니다. 자세한 작업 이야기는 아래에 따로 정리했습니다.

결과적으로 단순한 번역 패치보다는, 오래된 게임을 지금 다시 즐겨도 어색하지 않도록 한 번 더 손질한 작업에 가까워진 것 같습니다.

02-A / WORK PROCESS

약 3주간의 작업기

처음부터 모든 대사와 시스템 텍스트, 주요 타이틀 그래픽까지 한국어화하는 것이 목표였습니다. 그런데 계획에 없던 영상 작업이 점점 커지면서 예상보다 훨씬 긴 프로젝트가 되었습니다.

처음부터 목표가 작았던 것은 아닙니다. 스토리와 전투 대사, 메뉴와 시스템 문구를 전부 한국어로 옮기고, 타이틀과 에피소드 제목 같은 주요 그래픽도 한글화하는 것이 애초의 목표였습니다.

작업 범위가 예상 밖으로 가장 크게 번진 부분은 영상이었습니다. 본편 텍스트를 거의 다 한국어로 바꾸고 나니 에피소드 사이의 영상과 다음 화 예고에서 일본어 음성이 그대로 나오는 부분이 오히려 더 크게 느껴졌습니다. 특히 다음 화 예고의 내레이션은 다음 내용을 설명하는 역할을 하기 때문에, 본편만 한국어로 만들어 놓고 그 부분을 알아들을 수 없게 남겨 두기는 어려웠습니다.

그래서 내레이션 자막은 선택이라기보다 사실상 할 수밖에 없는 작업이 되었습니다. 오프닝과 본편 영상, 다음 화 예고, 예고 내레이션까지 하나씩 자막을 넣었고, 타이틀과 내레이션이 동시에 나오는 장면에서는 서로 겹치지 않도록 위치도 다시 잡았습니다. 영상마다 폰트와 크기, 색상과 외곽선까지 실제 PS1 화면에서 읽기 편한 쪽으로 계속 조정하다 보니 결국 대부분의 STR 영상을 다시 들여다보게 되었습니다.

다만 끝까지 예외로 남긴 부분도 있습니다. 합체 시뮬레이션에서 나오는 일부 영상은 구조상 안정적으로 자막을 삽입하기 어려워 원본 그대로 유지했습니다. 억지로 건드려 재생이나 진행에 문제가 생기는 것보다 원본을 보존하는 편이 낫다고 판단했습니다.

마지막에는 에뮬레이터에서 전혀 문제가 없던 C02 동영상이 실제 PlayStation에서는 멈추고 소리만 반복되는 문제까지 만났습니다. 원인을 추적한 끝에 교체한 STR의 Mode2 섹터 EDC/ECC를 실제 들어갈 LBA 기준으로 다시 생성했고, 문제가 발생했던 C02 영상은 실기에서 정상 재생되는 것까지 확인한 뒤 다시 배포할 수 있었습니다.

결과적으로 약 3주 동안 작업하면서 처음 계획했던 모든 대사와 타이틀 한글화에서 시작해, 게임을 처음부터 끝까지 플레이할 때 한국어 흐름이 최대한 끊기지 않도록 영상과 내레이션까지 범위를 넓히게 되었습니다.

03-A / SECRET FEATURE

げんき — 숨겨진 진 겟타 변화

여성 주인공을 선택한 뒤 이름을 원작 《진 겟타로보 세계 최후의 날》의 설정에 맞춰 げんき라고 입력하면 능력치 성장률이 상승하고, 진 겟타의 외형이 코믹스 버전에서 《세계 최후의 날》 버전으로 바뀌는 소소한 특징이 있습니다.

REQUIRED여성 + げんき
여성 주인공을 선택한 뒤, 반드시 히라가나 げんき로 입력해야 합니다.

남성 주인공을 선택하거나 ゲンキ, 겐키 등 다른 표기로 입력하면 해당 조건을 만족하지 않습니다.

03-B / NOTES

원본 그대로 남겨 둔 부분

게임 전체를 가능한 한 한국어로 즐길 수 있도록 손봤지만, 몇 군데는 끝까지 한글로 바꾸지 않았거나 원본을 유지한 부분이 있습니다. 미리 알고 플레이하면 덜 어색할 것 같아 함께 적어 둡니다.

NAME ENTRY

이름 입력 화면과 문자 자판

이름 입력과 성별 선택 화면의 일부 표기, 문자 자판은 원본 일본어 구조가 남아 있습니다. 특히 숨겨진 진 겟타 변경 조건은 이름을 히라가나 げんき로 입력해야 하기 때문에 해당 입력 환경을 그대로 사용할 수 있도록 두었습니다.

MOVIE

대사가 없는 영상은 원본 유지

한국어 자막이 필요한 영상에는 자막을 넣었지만, 대사가 없거나 자막이 필요하지 않은 영상은 원본 그대로 유지했습니다. 불필요하게 영상을 재가공하지 않고 원작 화면을 보존했습니다.

COMBINATION SIMULATION

합체 시뮬레이션 영상

합체 시뮬레이션에서 나오는 일부 영상은 구조상 안정적인 자막 삽입이 어려워 원본 그대로 남겼습니다. 재생이나 진행 안정성을 우선해 해당 부분에는 자막을 넣지 않았습니다.

※ v1.0은 전체 정적 QA와 에뮬레이터 기반 런타임 검증을 완료했습니다. 전체 구간의 PlayStation 실기 플레이 검수는 진행하지 않았지만, 문제가 확인됐던 C02 동영상 재생은 실기에서 PASS를 확인했습니다.
