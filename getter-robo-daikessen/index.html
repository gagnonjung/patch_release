INTRODUCTION

여러 세대의 겟타가 한자리에 모이는 대결전

1999년 PlayStation으로 발매된 《겟타로보 대결전!》은 여러 세대의 겟타로보와 파일럿이 한 작품에 등장하고, 전투와 합체·변형, 에피소드 연출을 함께 즐길 수 있는 작품입니다.

TV 애니메이션과 코믹스, 진 겟타 계열의 설정이 한 게임 안에서 교차하기 때문에 기체와 기술, 인물의 차이를 찾아보는 재미도 큽니다. 이번 한국어 패치는 그 분위기를 해치지 않으면서 게임 본편부터 영상 연출까지 최대한 자연스럽게 이어지도록 작업했습니다.

02 / OVERVIEW

개요

처음에는 대사와 메뉴, 몇몇 그래픽만 손보면 될 줄 알았습니다. 그런데 플레이할수록 ‘여기도 고치고 싶다’는 곳이 계속 보여, 결국 게임 전체를 다시 훑어보게 됐습니다.

스토리와 전투 대사, 메뉴와 이름·기술명은 물론 에피소드 제목과 각종 화면도 하나씩 다듬었습니다. 한 군데를 고치면 다른 곳이 눈에 들어오는 식이라, 마지막까지 에뮬레이터 플레이 화면을 보면서 계속 손봤습니다.

특히 에피소드 제목과 다음 화 예고, 영상 자막은 단순히 한국어를 넣는 것보다 원래 작품의 분위기를 얼마나 자연스럽게 살릴 수 있느냐를 더 중요하게 생각했습니다. 자세한 작업 이야기는 아래에 따로 정리했습니다.

결과적으로 단순한 번역 패치보다는, 오래된 게임을 지금 다시 즐겨도 어색하지 않도록 한 번 더 손질한 작업에 가까워진 것 같습니다.

스토리 · 전투메뉴 · 시스템에피소드 그래픽영상 · 예고 자막

04MOVIE / SUBTITLES

영상 자막

오프닝과 본편 영상, 다음 화 예고와 내레이션에 한국어 자막을 추가하고 화면별 위치와 가독성을 조정했습니다.

SUBTITLE STYLE2000s PC ANIME

자막 스타일 참고

영상 자막은 2000년대 초반 사사미 같은 플레이어로 애니메이션을 보던 시절의 팬자막을 참고했습니다. 굵은 흰 글씨와 검은 외곽선을 기본으로 하되, PS1 화면에서 지나치게 튀지 않도록 크기와 위치를 조정했습니다.

당시 느낌을 그대로 재현하기보다는 그 시절 자막의 인상을 남기면서 지금 봐도 편하게 읽히는 수준을 기준으로 정리했습니다.

03-A / SECRET FEATURE

げんき — 숨겨진 진 겟타 변화

여성 주인공을 선택한 뒤 이름을 원작 《진 겟타로보 세계 최후의 날》의 설정에 맞춰 げんき라고 입력하면 능력치 성장률이 상승하고, 진 겟타의 외형이 코믹스 버전에서 《세계 최후의 날》 버전으로 바뀌는 소소한 특징이 있습니다.

REQUIRED여성 + げんき
여성 주인공을 선택한 뒤, 반드시 히라가나 げんき로 입력해야 합니다.

남성 주인공을 선택하거나 ゲンキ, 겐키 등 다른 표기로 입력하면 해당 조건을 만족하지 않습니다.

03-B / NOTES

원본 그대로 남겨 둔 부분

게임 전체를 가능한 한 한국어로 즐길 수 있도록 손봤지만, 몇 군데는 끝까지 한글로 바꾸지 않았거나 원본을 유지한 부분이 있습니다. 미리 알고 플레이하면 덜 어색할 것 같아 함께 적어 둡니다.

NAME ENTRY

이름 입력 화면과 문자 자판

이름 입력과 성별 선택 화면의 일부 표기, 문자 자판은 원본 일본어 구조가 남아 있습니다. 특히 숨겨진 진 겟타 변경 조건은 이름을 히라가나 げんき로 입력해야 하기 때문에 해당 입력 환경을 그대로 사용할 수 있도록 두었습니다.

MOVIE

대사가 없는 영상은 원본 유지

한국어 자막이 필요한 영상에는 자막을 넣었지만, 대사가 없거나 자막이 필요하지 않은 영상은 원본 그대로 유지했습니다. 불필요하게 영상을 재가공하지 않고 원작 화면을 보존했습니다.

※ 현재는 정식 배포 전 최종 검수 단계이며, 에뮬레이터 기반으로 검증했습니다. 실제 PlayStation 실기 테스트는 진행하지 못했습니다. 새로 발견되는 문제는 제보를 받아 계속 다듬을 예정입니다.
