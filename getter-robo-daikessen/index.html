INTRODUCTION

여러 세대의 겟타가 한자리에 모이는 대결전

《겟타로보 대결전!》은 TechnoSoft가 개발하고 Bandai Visual이 발매한 PlayStation용 전술 시뮬레이션 RPG로, 일본에서 1999년 9월 9일 출시되었습니다. 겟타로보만의 세계관을 중심에 놓고 여러 시대의 기체와 파일럿을 한 작품 안에서 만나게 한 크로스오버 성격의 게임입니다.

플레이어는 사오토메 연구소의 견습 파일럿으로 이야기를 시작해 훈련과 실전을 거치며 다양한 로봇을 운용하게 됩니다. 전투는 턴 단위로 유닛을 이동하고 공격·필살기·지원 행동을 선택하는 방식이며, 기체별 능력과 지형, 적의 배치를 읽는 전술성이 핵심입니다.

등장 작품의 범위도 넓습니다. 초대 《겟타로보》와 《겟타로보 G》, 《겟타로보 고》를 비롯해 OVA 계열과 당시의 진 겟타 설정까지 여러 매체의 로봇과 캐릭터가 한데 모이며, 게임만의 오리지널 요소도 더해져 있습니다. 합체와 변형, 필살기 연출이 전투의 중요한 볼거리로 배치되어 원작 팬을 위한 팬서비스의 비중도 큽니다.

이번 한국어 패치는 이러한 작품의 분위기를 해치지 않으면서 스토리와 전투 대사, 시스템 UI, 그래픽, 영상 자막까지 자연스럽게 이어지도록 전체 흐름을 다듬었습니다.

02 / OVERVIEW

개요

처음에는 대사와 메뉴, 몇몇 그래픽만 손보면 될 줄 알았습니다. 그런데 플레이할수록 ‘여기도 고치고 싶다’는 곳이 계속 보여, 결국 게임 전체를 다시 훑어보게 됐습니다.

스토리와 전투 대사, 메뉴와 이름·기술명은 물론 에피소드 제목과 각종 화면도 하나씩 다듬었습니다. 한 군데를 고치면 다른 곳이 눈에 들어오는 식이라, 마지막까지 에뮬레이터 플레이 화면을 보면서 계속 손봤습니다.

특히 에피소드 제목과 다음 화 예고, 영상 자막은 단순히 한국어를 넣는 것보다 원래 작품의 분위기를 얼마나 자연스럽게 살릴 수 있느냐를 더 중요하게 생각했습니다. 자세한 작업 이야기는 아래에 따로 정리했습니다.

결과적으로 단순한 번역 패치보다는, 오래된 게임을 지금 다시 즐겨도 어색하지 않도록 한 번 더 손질한 작업에 가까워진 것 같습니다.

03-A / SECRET FEATURE

한국어 키보드와 겐키 — 숨겨진 진 겟타 변화

v1.1부터 이름 입력 화면에 한국어 키보드를 추가했고, v1.11에서는 입력 화면을 한글·영문기호 두 페이지로 정리했습니다. 주인공 이름을 한글로 직접 입력할 수 있고, 초성·중성·종성 조합과 단계별 Backspace를 지원합니다. 이름을 비운 채 START를 누르면 기본 이름인 아키라·케이가 적용되는 기존 동작도 유지됩니다. 왼쪽 스크린샷은 여성 주인공 이름에 겐키를 입력한 화면입니다.

이 기능은 생각보다 만만치 않았습니다. 한글 조합 입력을 구현하는 과정에서 기존 전투 데이터와 충돌해 게임이 프리징되는 문제가 생기는 바람에 한동안 원인을 추적하느라 진땀을 뺐습니다. 결국 이름 입력 엔진을 안전한 영역으로 재배치하고 기존 동작까지 다시 검증해 안정화했습니다.

원작에는 여성 주인공의 이름을 특정 조건에 맞추면 능력치 성장률이 상승하고, 진 겟타의 외형이 코믹스 버전에서 《세계 최후의 날》 버전으로 바뀌는 숨겨진 요소가 있습니다.

KOREAN INPUT여성 + 겐키
v1.11에서는 여성 주인공의 이름을 겐키로 입력하면 원작의 숨겨진 이름 조건에 연결됩니다.

한국어 키보드에서 실제로 조합되는 겐키 값을 원작의 이름 비교 루틴에 연결했습니다. 원작의 비교·모델 변경 코드는 그대로 유지하고 비교 문자열만 한글 입력 결과에 맞췄으며, 관련 정적·디스크 QA를 완료했습니다.

v1.12 / 2026.10.07

누락 에피소드 제목 이미지 3건 한국어화

  • 제9화 「진 겟타로보」 제목 이미지를 한국어화했습니다.
  • 제15화 C 분기 「부활한 제왕」 제목 이미지를 기존 확정 번역으로 반영했습니다.
  • 같은 누락 패턴의 제15화 A 분기 「공포의 거대 회오리」 제목 이미지도 함께 한국어화했습니다.
  • v1.11의 한글 이름 입력·Backspace·아키라/케이 기본 이름·2페이지 UI·겐키 숨겨진 조건 연동과 기존 번역은 그대로 유지합니다.
  • 3개 고정 PAC payload window만 변경했으며 v1.11 대비 56개 섹터 변경, 전체 VFS readback·root EXE 동기화·EDC/ECC·Xdelta replay QA를 통과했습니다.
  • 새 제목 이미지의 실제 해당 화 Runtime 확인은 현재 대기 상태입니다.
v1.11 / 2026.09.29

이름 입력 2페이지 정리 · 겐키 숨겨진 조건 연동

  • 이름 입력 화면을 한글 / 영문기호 두 페이지로 정리하고 숨겨진 카타카나 선택 경로와 커서 진입을 제거했습니다.
  • 한국어 키보드에서 조합한 겐키를 원작의 숨겨진 이름 비교 루틴과 연결했습니다.
  • 겐키만 원작의 모델 변경 분기로 진입하도록 실제 한글 입력 결과에 맞춰 비교값을 수정했습니다.
  • v1.1의 한글 조합·단계별 Backspace·아키라/케이 기본 이름 경로와 기존 번역·그래픽·영상 수정은 그대로 유지했습니다.
  • v1.1 대비 변경 섹터 7개를 확인하고 VFS readback, root EXE 일치, Mode2/Form1 EDC/ECC, Xdelta 재적용 해시를 재검증했습니다.
  • 최종 v1.11 빌드 사용자 스모크 테스트 PASS
v1.1 / 2026.09.29

한글 이름 입력 보강 · 남은 미번역/표기 수정

  • 이름 입력 엔진을 안전하게 재배치하고 아키라/케이 기본 이름 START 경로를 유지했습니다.
  • 겐키 조합과 단계별 Backspace 동작을 보강했습니다.
  • 주인공의 ‘박사님’ 호칭을 정리하고 ‘이동할 곳 선택’ UI 3곳을 한국어화했습니다.
  • 겟타 머신건 / 겟타 빔 런처 신규 무장 안내 이벤트와 사오토메 연구소 환영 대사를 한글화·정리했습니다.
  • C10 영상 자막의 ‘기임바그,’를 ‘고르,’로 수정하고 MFORM06B 브라이 대제 분기를 재검증했습니다.
  • v1.1 최종본의 PlayStation 실기 동작을 확인했습니다.
  • 최종 디스크 예상 밖 쓰기 0, 변경하지 않은 섹터 byte-identical, Xdelta replay byte-identical PASS
v1.0 / 2026.09.10

실기 동영상 재생 안정화 · 배포 재개

  • 실기에서 확인된 C02 동영상 멈춤 및 사운드 반복 문제를 수정했습니다.
  • 교체 STR 14개 전 Mode2 섹터의 EDC/ECC를 목적 LBA 기준으로 재생성했습니다.
  • 문제 구간 C02 동영상 재생을 실제 PlayStation에서 PASS 확인했습니다.
  • 최종 디스크 fixed-extent · directory · unused-tail 검증 PASS
  • Xdelta direct replay로 일본판 원본 → 최종 한국어판 BIN byte-identical PASS
