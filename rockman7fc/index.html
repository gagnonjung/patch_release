내장된 프리즈맨 NES 개발판이 자동 실행됩니다. 다른 ROM을 테스트하려면 NES ROM 선택을 누르세요.

키보드 조작
  • 이동 ← → / 점프 X / 버스터·차지 Z / 슬라이딩 ↓+X
  • START Enter / SELECT 오른쪽 Ctrl · 터치와 게임패드 입력도 지원
  • 개발용 스테이지 방 이동: START+위/아래, 보스 방 이동: START+SELECT

이 버전은 록맨6 플레이어 조작을 적용한 프리즈맨 29개 방 테스트판으로, 록맨7 전체 완성판은 아닙니다.

내장 NES 개발 ROM은 공개 GitHub 저장소에서 제공됩니다. 비공식 팬게임 포팅 테스트판입니다. JSNES 2.1.0 (Apache-2.0)
