카르나크 유적을 탐험하는 1인칭 슈팅

고대 이집트를 무대로 한 1인칭 슈팅 게임. 미라와 괴물을 상대하며 유적을 탐험하고, 새 능력을 얻은 뒤 이전 지역으로 돌아가 닫혀 있던 길을 여는 구조가 특징이다.

숨겨진 통신기를 모으면 결말이 달라진다스테이지마다 숨겨진 통신기를 찾아 모으는 것이 엔딩 조건과 연결된다.

현대 무기와 고대의 힘을 함께 사용무기와 유물을 확보하며 점프·이동 능력을 확장해 닫힌 길을 다시 탐험한다.

원작에서는 자막 없이 들리던 일본어 음성에 한국어 자막이 나오도록 게임용 표시 기능을 새로 만들었습니다. 음성 14개 파일의 대사에 대응하는 102개 자막 초안을 개발본에 통합했습니다.

오프닝·엔딩 영상에도 새 자막

원래 자막이 없던 오프닝과 두 종류의 엔딩에 한국어 자막을 직접 구성했습니다. 일본어 음성은 그대로 두고 영상 안에서 내용을 읽을 수 있도록 44개 자막 초안을 넣었습니다.

새로운 자막 기능과 함께 메뉴·설정·저장·이동 안내 등 일반 UI 118개 항목도 한국어로 옮겼습니다. 원본 그래픽과 주요 영문 표기는 보존합니다.

원작에 없던 자막 표시 기능을 구현하고 기본 검수를 완료했습니다. 원본 일본어 음성은 그대로 유지하며, BONUS 화면의 영문 UI 27개도 원문을 보존합니다. 전체 진행 분기와 실기 환경별 검증은 기본 검수와 별개입니다.

패치 적용 방법

  1. ZIP을 새 폴더에 풀고, 세가 새턴 일본판 T-18001G V1.003의 CUE 1개와 BIN 14개를 준비합니다.
  2. 원본 CUE 파일 또는 원본 게임 폴더를 패치하기_0.8b.cmd 위로 끌어다 놓습니다. Windows PowerShell 5.1 이상을 사용합니다.
  3. 스크립트는 원본 트랙·패치·도구의 SHA-256을 확인하고, 원본 옆에 Seireki 1999 - Pharaoh no Fukkatsu (Korea) 폴더를 만들어 한국어판 BIN 14개와 CUE를 구성합니다.
  4. 새로 만든 Seireki 1999 - Pharaoh no Fukkatsu (Korea).cue로 처음부터 부팅합니다. 이전 개발본의 부팅 후 상태 저장은 사용하지 마세요.

원본 BIN/CUE는 덮어쓰지 않으며 오디오 13트랙은 원형 보존합니다. 0.8a를 포함한 기존 한국어판 BIN에 중복 적용하지 말고 일본판 원본을 이용하세요. 자세한 안내와 검수 항목은 ZIP 내부의 README.ko.md와 TEST_GUIDE.md를 참조하세요.

파일 이용에 관한 권리 및 책임 고지

파일 다운로드 전에 아래 사항을 반드시 확인 바랍니다.

  1. 원칙적으로, 해당 기종의 원본 디스크 또는 카트리지를 보유한 분이 개인적으로만 이용한다는 전제 하에 본 한글패치 파일을 다운로드할 수 있습니다.
  2. 상기 A항 조건에 해당하지 않는 분이 본 한글패치 파일을 다운로드하여 이용할 경우에 발생하는 모든 책임은 이용 당사자에게 있으며, 패치 제작자는 어떠한 책임도 지지 않습니다.
  3. 본 한글패치 파일 자체를 제작자의 허가 없이 타 사이트에 재배포하지 말아 주시고, 재배포를 원하실 경우 패치원본 게시물의 링크를 공유해 주시기 바랍니다.(아카이빙 포함)
  4. 본 게시물의 본문 글 일부 또는 전체를 무단으로 옮겨 작성하지 말아 주시기 바랍니다. 단, 타 사이트에서 발췌하거나 인용한 문구에 대해서는 예외로 합니다.
  5. 본 한글패치 파일을 이용하여 금전적 이득을 취하는 모든 행위를 일절 금합니다. 해당 행위로 발생하는 모든 책임은 이용 당사자에게 있으며, 패치 제작자는 어떠한 책임도 지지 않습니다.(패치 파일 자체 및 패치 롬 파일 판매, 패치 롬 카트리지 제작 및 판매, 웹하드 등 상업적 사이트 업로드, 토렌트 사이트 공유 등)
  6. 상기 C·D·E항의 금지 행위가 적발된 경우, 또는 본 한글패치 파일 공유로 인해 원저작자 및 유통사, 기관의 요청이 있을 경우 예고 없이 게시물이 비공개 처리될 수 있으며, 향후 작업 예정인 작품의 한글패치 파일도 공유하지 않을 수 있습니다.
