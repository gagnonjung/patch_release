02 / OVERVIEW

개요

메탈 기어 솔리드: 더 트윈 스네이크스는 2004년 3월 11일 일본에서 발매된 닌텐도 게임큐브용 타이틀입니다. 이번 한국어 패치는 일본판 정품 Disc 1·Disc 2를 대상으로 제작했으며, 원작의 분위기와 인물별 말투를 살리면서 게임 전체를 자연스럽게 플레이할 수 있도록 텍스트와 화면 출력을 함께 다듬는 것을 목표로 합니다.

패치에는 일반 및 자동 호출을 포함한 CODEC 무전, 컷신 자막, 메뉴·아이템·저장·언어 설정 등 주요 시스템 텍스트, 스테이지명과 각종 안내 문구의 한국어화가 포함됩니다. 단순히 일본어 문자열을 한국어로 교체하는 방식에 그치지 않고, 한글 폰트와 글리프 처리, 문장별 줄바꿈과 출력 폭, 자막 타이밍, UI 정렬과 가독성도 한국어 환경에 맞춰 조정했습니다.

텍스트 삽입 이후 실제 플레이에서 발생할 수 있는 글자 깨짐, 폭 초과, 무전 표시 오류, 로딩 프리징 등의 문제를 반복 검증했습니다. v1.03에서는 v1.02의 stage.dat fixed-span 안정성 수정을 유지하면서 컨트롤러 포트·도그 태그 불러오기 완료 문구를 추가 한글화하고, 메릴·나오미·사이코 맨티스 대사와 PSG1/PSG1-T 설명 조판을 재검수했습니다. 또한 CODEC·컷신·VOX의 문장 경계 34건과 문장부호 뒤 붙은 어절 5건을 추가 교정했습니다.

배포 ZIP에는 Disc 1·Disc 2용 xdelta 패치와 Windows용 적용 스크립트가 포함되어 있습니다. 원본의 MD5를 자동으로 판별한 뒤 해당 패치를 적용하고, 완성된 ISO의 SHA-256까지 검증하도록 구성했습니다. 원본 게임 데이터는 배포본에 포함되지 않으며, 사용자가 소유한 지원 일본판 원본을 기준으로 패치를 적용해야 합니다.

04-B / INSTALL GUIDE

적용 방법

01

ZIP 전체 압축 해제

MGS_TTS_KO_v1.03_xdelta_windows.zip의 내용을 한 폴더에 모두 압축 해제합니다.

02

일본판 원본을 BAT에 드래그 앤 드롭

정품 Disc 1 또는 Disc 2 원본 파일을 apply_patch.bat 위로 끌어다 놓습니다. 파일명과 확장자는 판별에 사용하지 않으며, 두 파일을 동시에 선택해도 됩니다.

03

MD5 자동 판별 · xdelta 적용

BAT가 원본의 MD5를 계산해 Disc 1 / Disc 2를 자동 판별하고, 지원 원본과 일치할 때 해당 xdelta를 적용합니다.
