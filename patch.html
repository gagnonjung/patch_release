PROLOGUE

사상 초유의 핵무기 탈취 사건

2005년, 알래스카의 섀도우 모세스 섬에 있는 핵무기 폐기시설이 특수부대 FOXHOUND에 의해 점거된다. 그들은 전설의 병사 빅 보스의 유해를 요구하며, 24시간 안에 요구가 받아들여지지 않으면 핵을 발사하겠다고 위협한다.

정부는 은둔 생활을 하던 전 FOXHOUND 대원 솔리드 스네이크를 소환해 단독 잠입 임무를 맡긴다. 인질을 구출하고, 테러리스트를 제거하며, 핵 위협을 해제하라. 스네이크는 홀로 섀도우 모세스 섬으로 향한다.

02 / OVERVIEW

개요

메탈 기어 솔리드: 더 트윈 스네이크는 2004년 3월 11일 일본에서 발매된 닌텐도 게임큐브용 타이틀입니다. 저는 일본판 정품 Disc 1·Disc 2를 기준으로 작업했고, 원작의 분위기와 인물별 말투를 최대한 살리면서 처음부터 끝까지 자연스럽게 플레이할 수 있도록 다듬었습니다.

CODEC 무전과 컷신 자막, 메뉴·아이템·저장·언어 설정, 스테이지명과 각종 안내 문구까지 게임에서 보이는 일본어를 전반적으로 한국어화했습니다. 번역만 넣고 끝내지 않고 한글 폰트, 줄바꿈, 글자 폭, 자막 타이밍, 메뉴 정렬도 실제 화면을 보면서 손봤습니다.

작업 중에는 글자가 깨지거나 화면 밖으로 넘어가는 문제, 무전 표시 오류, 특정 구간에서 멈추는 문제도 여러 번 만났습니다. 그때마다 원인을 찾아 수정하고 다시 플레이해 확인했습니다. v1.1에서는 Mission Log와 Demo Theater, Disc 2 후반부까지 다시 검토했고, v1.11에서는 배포 이후 제보된 버그를 다시 확인해 수정했습니다.

배포 ZIP에는 Disc 1·Disc 2용 xdelta 패치와 Windows용 적용 파일을 함께 넣었습니다. 원본 파일이 지원 대상인지 확인한 뒤 패치를 적용하고, 완성된 ISO가 정상인지까지 확인하도록 해 두었습니다. 원본 게임 데이터는 배포본에 포함하지 않았으며, 가지고 있는 일본판 정품 원본에 직접 패치를 적용하면 됩니다.

04-B / INSTALL GUIDE

적용 방법

01

ZIP 전체 압축 해제

MGS_TTS_KO_v1.11_xdelta_windows.zip의 내용을 한 폴더에 모두 압축 해제합니다.

02

일본판 원본을 BAT에 드래그 앤 드롭

정품 Disc 1 또는 Disc 2 원본 파일을 apply_patch.bat 위로 끌어다 놓습니다. 파일명과 확장자는 판별에 사용하지 않으며, 두 파일을 동시에 선택해도 됩니다.

03

MD5 자동 판별 · xdelta 적용

BAT가 원본의 MD5를 계산해 Disc 1 / Disc 2를 자동 판별하고, 지원 원본과 일치할 때 해당 xdelta를 적용합니다.

04

완성된 ISO 확인
