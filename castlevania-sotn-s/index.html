PlayStation을 기반으로 새턴판 콘텐츠를 더한 변형판

원래 PlayStation으로 출시된 『월하의 야상곡』에 세가 새턴판 콘텐츠를 이식한 별도 구성입니다. 정확히 어떤 콘텐츠가 포함되는지는 실제 이식판 빌드와 테스트 결과를 확인한 뒤 안내합니다.

확장되는 탐험성의 각 구역이 서로 이어져 있어 이전에 방문한 장소로 되돌아가는 과정도 중요합니다.

무기·마법·변신다양한 장비와 특수 능력의 조합에 따라 전투와 탐색 방식이 달라집니다.

게임 화면: FantasyAnime · PS1 일반판 원작 화면 (S 적용 화면이 아님). 커버: LaunchBox · 세가 새턴 원작판 참고 이미지 (S의 별도 패키지가 아님).

세가 새턴판에 있던 콘텐츠를 PlayStation 기반 게임에 반영하는 별도 이식판입니다. 개별 구현 목록은 확인 후 갱신합니다.

저장 데이터 분리

일반 PlayStation판과 S 이식판은 저장 파일이 서로 호환되지 않으므로 별도 관리해야 합니다.

세가 새턴판 콘텐츠의 구체적인 이식 범위와 기능별 동작 상태는 배포용 빌드 검증 후 기재합니다.

두 버전 구분 및 세이브 호환

월하의 야상곡 (일반판): PlayStation 일본어판 Rev 2를 기반으로 한 일반판 한국어 패치입니다.

월하의 야상곡 S: 세가 새턴판 콘텐츠를 PlayStation 기반 게임에 이식한 별도 패치입니다. 현재 페이지입니다.

주의: 일반 PlayStation판 『월하의 야상곡』과 새턴 콘텐츠 이식판 『월하의 야상곡 S』는 서로 저장 파일이 호환되지 않습니다. 한쪽의 세이브 파일을 다른 쪽에서 불러오지 말고, 각각 별도 슬롯과 백업을 사용해 주세요.

한국어 패치

S VERSION · 준비 중

월하의 야상곡 S · 별도 패치

『월하의 야상곡 S』는 일반 PlayStation판 v0.9b와 별도 관리하는 이식판입니다. 다운로드가 준비되면 한마루 티스토리의 S 전용 게시물로 연결합니다. 일반판 패치를 S에 그대로 적용하면 안 됩니다.

원본 게임 BIN/CUE 등 게임 데이터는 제공하지 않습니다. 패치 파일의 다운로드 URL과 원본·패치 후 MD5는 확인 후 등록합니다.

패치 적용 방법

  1. 원본 일본어판 디스크 이미지와 저장 파일을 백업합니다.
  2. S 이식판 전용 패치에 명시된 지원 원본 리비전과 MD5를 확인합니다. 일반판 패치를 사용하지 마세요.
  3. 패치 형식과 실행 방식은 실제 배포 패키지의 설명서를 기준으로 적용합니다.

현재는 S 이식판의 패치 형식이나 실행 파일 이름을 확정하지 않았습니다. 일반 PlayStation판과 S 이식판의 저장 파일은 서로 호환되지 않으므로 반드시 별도로 백업해 주세요.

파일 이용에 관한 권리 및 책임 고지

파일 다운로드 전에 아래 사항을 반드시 확인 바랍니다.

  1. 원칙적으로, 해당 기종의 원본 디스크 또는 카트리지를 보유한 분이 개인적으로만 이용한다는 전제 하에 본 한글패치 파일을 다운로드할 수 있습니다.
  2. 상기 A항 조건에 해당하지 않는 분이 본 한글패치 파일을 다운로드하여 이용할 경우에 발생하는 모든 책임은 이용 당사자에게 있으며, 패치 제작자는 어떠한 책임도 지지 않습니다.
  3. 본 한글패치 파일 자체를 제작자의 허가 없이 타 사이트에 재배포하지 말아 주시고, 재배포를 원하실 경우 패치원본 게시물의 링크를 공유해 주시기 바랍니다.(아카이빙 포함)
  4. 본 게시물의 본문 글 일부 또는 전체를 무단으로 옮겨 작성하지 말아 주시기 바랍니다. 단, 타 사이트에서 발췌하거나 인용한 문구에 대해서는 예외로 합니다.
  5. 본 한글패치 파일을 이용하여 금전적 이득을 취하는 모든 행위를 일절 금합니다. 해당 행위로 발생하는 모든 책임은 이용 당사자에게 있으며, 패치 제작자는 어떠한 책임도 지지 않습니다.(패치 파일 자체 및 패치 롬 파일 판매, 패치 롬 카트리지 제작 및 판매, 웹하드 등 상업적 사이트 업로드, 토렌트 사이트 공유 등)
  6. 상기 C·D·E항의 금지 행위가 적발된 경우, 또는 본 한글패치 파일 공유로 인해 원저작자 및 유통사, 기관의 요청이 있을 경우 예고 없이 게시물이 비공개 처리될 수 있으며, 향후 작업 예정인 작품의 한글패치 파일도 공유하지 않을 수 있습니다.
