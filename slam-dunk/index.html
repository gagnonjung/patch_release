02 / INTRODUCTION

게임 소개

《슬램덩크 I Love Basketball》은 TV 애니메이션을 바탕으로 북산과 도내 라이벌 학교들의 농구 경기를 다룬 게임입니다. 이야기를 따라 경기를 치르는 스토리 모드와 여러 팀으로 겨루는 대전 모드를 갖추고 있으며, 선수들의 특징적인 움직임과 애니메이션 영상, 캐릭터 음성을 함께 즐길 수 있습니다.

한국어화에서는 국내 정식 발매 만화의 인명·학교명·호칭을 기준으로 용어를 통일하고 있습니다. 음성 대사와 영상 자막, 선수 명단, 경기·보너스 UI, 정지 이미지에 남은 일본어를 각각 분리해 작업합니다.

03 / PREVIEW

게임 화면과 한국어 그래픽 시안

스크린샷은 원본 게임 화면 및 별도 정적 그래픽 시안입니다. 미완성 그래픽을 실제 게임에서 검증한 것으로 표시하지 않습니다.

04 / LOCALIZATION SCOPE

한국어화 작업 범위

01 / GRAPHICS선수명과 정지 그래픽

경기·결과 화면의 선수명과 안내 문구를 원본 그래픽의 크기·팔레트·압축 제한에 맞춰 교체하고 있습니다. 선수명은 움돋 일반체 12px 기준으로 관리합니다.

02 / MOVIE영상·음성 자막

세가 FILM/CPK 영상 속 대사 및 일본어 자막을 장면별로 정리하며, 비디오 프레임과 오디오 데이터의 정적 무결성을 검증하고 있습니다.

03 / UI경기·보너스 메뉴

경기 조작 설명, 편성·상태 표시, 보너스 메뉴 등 여러 그래픽 소비처를 확인합니다. 해금 조건과 기존 게임 로직은 별도로 보존·검증합니다.

04 / REVERSE ENGINEERING리소스 추출·구조 검증

CG 이미지와 SH-2 코드를 분석해 포인터, 팔레트, 스프라이트 경계와 원본 파일 크기를 대조합니다. 미확인 구조는 실제 패치에 적용하기 전 보류합니다.

팀 로고·엠블럼·학교 제목 그래픽은 사용자 검수 전까지 원본 그대로 보존합니다.

05 / PROJECT STATUS

진행 현황 및 검수

PROJECT / ACTIVE정적 QA / 부분 통과런타임 / 검증 대기

현재 공개 배포된 완성 패치는 없습니다. 정지 이미지와 선수명 그래픽, 자막 작업용 프레임, 리소스 분석기, 영상 검수 도구 등을 만들어 단계별로 검증하는 중입니다.

기존에 통과한 정적 검증이 전체 게임의 완료를 뜻하지는 않습니다. 일부 영상 재압축, 남은 일본어 확인, 실제 새턴·에뮬레이터 환경에서의 표시 검수 및 최종 패치 패키지 QA가 남아 있습니다.
